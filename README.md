# 너만 오면 GO Frontend

여행 예산과 일정에 맞춰 사용자가 더 쉽게 여행 계획을 세울 수 있도록 돕는 웹 서비스 **너만 오면 GO**의 프론트엔드 프로젝트입니다.  
사용자는 자신이 원하는 여행 장소를 입력하고, 이에 맞는 여행지 추천과 일정 구성을 한 화면 흐름 안에서 경험할 수 있습니다.

---

## 프로젝트 소개

기존 여행 계획 과정은 보통 여러 사이트를 오가며 숙소, 음식점, 관광지, 이동 거리를 따로 확인해야 해서 번거롭습니다.  
**너만 오면 GO**는 이런 불편을 줄이기 위해, 사용자가 입력한 조건을 바탕으로 여행 후보를 추천하고 여행 동선을 효율적으로 구성할 수 있도록 설계한 서비스입니다.

프론트엔드는 모바일 환경을 우선으로 고려하여 구현하였고, 직관적인 UI와 단계별 사용자 흐름을 통해 초보 사용자도 쉽게 여행 계획을 세울 수 있도록 구성했습니다.

---

## 프로젝트 목표

- 여행 예산과 일정에 맞는 여행 계획 UI 제공
- 복잡한 정보 탐색 과정을 줄일 수 있는 사용자 경험 설계
- 경로 생성, 추천, 저장 기능을 하나의 서비스 흐름으로 통합
- 백엔드 및 외부 API 연동을 고려한 프론트엔드 구조 설계
- 졸업 프로젝트에 맞는 실제 서비스 형태의 화면 구현

---

## 주요 기능

### 1. 랜딩 페이지
- 서비스 소개
- 시작하기 버튼 제공
- 전체 서비스 흐름 진입

### 2. 온보딩
- 사용자 입력 단계 제공
- 여행 스타일, 예산, 기간, 인원 등의 정보 입력
- 단계별 화면 이동 구성

### 3. 로그인
- 기본 로그인 UI
- 카카오, 네이버 소셜 로그인 UI 구성
- 이후 메인 서비스 화면으로 이동

### 4. 홈 화면
- 추천 여행지 카드 제공
- 빠른 메뉴 진입
- 서비스 핵심 기능으로 바로 이동 가능

### 5. 여행 경로 생성
- 날짜 선택
- 장소 검색 및 추가
- DAY별 일정 구성
- 여행 동선 최적화 기능과 연결될 수 있도록 화면 구조 설계

### 6. 테마 추천
- 힐링, 액티비티, 맛집 탐방 등 카테고리별 추천
- 카드형 UI 제공
- 좋아요 기능 등 사용자 인터랙션 반영

### 7. 마이페이지
- 저장한 장소 확인
- 사용자 정보 확인
- 추후 백엔드 연동을 고려한 확장 구조 반영

### 8. 공통 UI
- 헤더/푸터 컴포넌트 분리
- 모바일 퍼스트 레이아웃 적용
- 재사용 가능한 컴포넌트 중심으로 구성

## 프론트엔드 구현 포인트

### 모바일 퍼스트 UI
데스크톱 환경에서도 모바일 앱처럼 보이도록 최대 너비를 제한하고, 세로 중심의 화면 흐름으로 구현했습니다.

### 컴포넌트 분리
헤더, 푸터, 페이지별 UI를 분리하여 유지보수성과 재사용성을 높였습니다.

### 사용자 흐름 중심 설계
랜딩 → 온보딩 → 로그인 → 홈 → 기능 진입 구조로 이어지도록 설계하여 사용자가 자연스럽게 서비스 목적을 이해하고 사용할 수 있도록 구성했습니다.

### 목업 데이터 기반 개발
초기 프론트엔드 단계에서는 목업 데이터를 활용해 UI와 흐름을 먼저 구현하고, 이후 백엔드 API와 연결할 수 있도록 확장 가능한 구조를 고려했습니다.

## API 연동 계획

현재 프론트엔드는 일부 화면과 기능이 목업 데이터 기반으로 구현되어 있으며, 이후 백엔드와 연동하여 실제 데이터를 반영할 예정입니다.

예상 연동 방향은 다음과 같습니다.

- 일정 생성 및 저장
- 마이페이지 데이터 조회
- 위치 기반 서비스 및 지도 API 연동
