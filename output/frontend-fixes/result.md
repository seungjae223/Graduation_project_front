## 우선 수정 결과

- 홈 검색 한 번으로 URL 검색어 조회를 시작합니다. 재검색과 뒤로가기·앞으로가기·새로고침에서 URL·입력·결과가 일치하고, 추천 전체보기도 검색어를 유지합니다.
- 저장 해제는 실제 폴더 매핑과 DELETE 및 결과 조회에 근거합니다. 여러 폴더에 남은 저장 상태는 유지하며, 응답 유실을 성공이나 재전송 가능 상태로 추정하지 않습니다. Total·추천·상세·최근 장소에서 공통 저장 흐름을 사용합니다.

- 답변 대기 문의에서 예시 완료 문장과 가짜 날짜를 제거했습니다. 최신 권한 조회 실패는 전송을 막고, 답변 초안과 응답 유실 입력을 보존합니다.

## 공통 상태·비동기 처리

계정·조회 범위·요청 세대와 AbortSignal을 함께 확인해 늦은 성공·오류·finally가 현재 화면을 덮지 않도록 했습니다. 같은 계정과 범위에서 확인한 데이터는 갱신 실패만으로 지우지 않고, 다른 계정의 데이터는 재사용하지 않습니다. 전체 실패·부분 성공·정상 빈 결과·미확인 저장 상태를 구분합니다.
