API 및 장소 식별

Place 응답: id, region, name, address, latitude, longitude, theme, placeType, description. 국가/국가코드 및 이미지 필드는 없습니다. 국가코드는 기존 지역 분류에 맞춰 사진 메타데이터에 저장했고, API 응답을 변경하지 않았습니다. /api/places, /api/places/search, /api/recommendations는 배열 전체를 반환하며 기존 프론트엔드 페이지네이션을 유지했습니다.

SQL INSERT에 ID가 없으므로 행번호를 placeId로 사용하지 않음. 정확한 이름+지역/국가+주소(제공되는 경우)+좌표로 유일한 장소를 판별. 좌표 필수, SQL 기준 250m 이내. 확인된 DB ID를 추후 넣어도 이름/위치 모순을 거부. 런타임 사진 검색 없음.
